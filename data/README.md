# data/

**Nothing in this directory is committed except this README and `synthetic_fixture.csv`.**
The `.gitignore` at the repo root enforces that from the first commit.

## Why

The private-market side of this study uses a PitchBook export. PitchBook data is
licensed and may not be redistributed. To reproduce the real results you need
your own PitchBook access (many universities, including UC Berkeley, provide it).

## What the loader expects

Export a **sector x quarter** table from PitchBook and save it as
`data/pitchbook_export.csv`. The loader (`private_signals.loader.load_private`)
expects one row per (sector, quarter) with these columns:

| column             | type    | meaning                                          |
|--------------------|---------|--------------------------------------------------|
| `sector`           | string  | Sector key; must match a key in `SECTOR_MAP`     |
| `quarter`          | string  | Calendar quarter, e.g. `2019Q3`                  |
| `total_funding_usd`| float   | Sum of VC/growth deal value in the quarter, USD  |
| `deal_count`       | int     | Number of completed deals in the quarter         |
| `median_valuation_usd` | float | Median post-money valuation (may be blank)     |

Extra columns are ignored. Column names are matched case-insensitively after
stripping whitespace, and a few common PitchBook header spellings are aliased
(see `loader.COLUMN_ALIASES`). Sector names in PitchBook verticals do not map
one-to-one onto ETFs; `private_signals/sectors.py` documents the mapping used
and you should edit it to match how you built your export.

## How the real export was built (PitchBook, 6 Oct 2026)

Companies & Deals Screener, Deals search, with these criteria:

* Deal types: Early stage VC, Later stage VC, PE Growth/Expansion
* Deal status: Completed
* Deal date: 01-Jan-2014 to 30-Jun-2026 (search on the full transaction)
* Location: United States (company headquarters)

Then Pivot Table > Deals, rows = Year > Quarter, values = Deal Count,
Capital Invested (Sum, $M), Capital Invested (Count), Post Valuation (Median, $M),
and one download per column dimension, each saved under `data/raw/` (git-ignored):

| file                        | column dimension                   | labels used                     |
|-----------------------------|------------------------------------|---------------------------------|
| `pivot_primary_sector.xlsx` | Primary PitchBook Industry Sector  | IT, Healthcare, Financial Services, Energy, B2B |
| `pivot_industry_group.xlsx` | Primary PitchBook Industry Group   | Software, Semiconductors        |
| `pivot_industry_code.xlsx`  | Primary PitchBook Industry Code    | Biotechnology                   |
| `pivot_verticals.xlsx`      | Verticals                          | Cybersecurity, FinTech          |

`scripts/convert_pitchbook_pivot.py` turns those four pivots into
`data/pitchbook_export.csv` with the schema above (dollar columns converted
from $M to USD). The sector-to-label mapping is in `private_signals/sectors.py`.

Total in the base search: 121,202 deals across 69,981 companies.

## The synthetic fixture

`synthetic_fixture.csv` is **FAKE DATA**. It is generated by
`scripts/make_synthetic_fixture.py` from a seeded random process with **no**
relationship to real funding activity and **no** planted relationship to
returns. Its only purpose is to let the pipeline and tests run end to end
without any licensed data. Every figure and ledger entry produced from it is
labeled `SYNTHETIC`. Do not draw conclusions from it.

## Market data

Daily ETF prices come from Yahoo Finance via `yfinance` and are cached under
`cache/` (also git-ignored). They are re-downloaded on demand.
